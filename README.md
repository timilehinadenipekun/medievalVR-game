# Medieval Village VR — MM806 Assignment 2

A mobile virtual reality application developed in Unity using the Google Cardboard XR plugin. The project allows users to explore a low-poly medieval village through touchscreen controls or a Google Cardboard headset.

## Features

- Mobile navigation using a virtual joystick and swipe-to-look controls
- Adjustable field of view in mobile mode
- Switch from mobile mode to stereoscopic VR mode
- Head-tracked viewing in VR
- Gaze-directed movement using touch-and-hold input
- Double-tap movement speed boost

## Demonstration Video

The gameplay demonstration video is located in the **`Demo/`** folder of this repository. It shows the mobile controls, field-of-view adjustment, transition to VR, head tracking, and VR movement.

## Project Files

- `Assets/` — Unity scenes, scripts, and visual assets
- `Packages/` — Project dependencies
- `ProjectSettings/` — Unity project configuration
- `Demo/` — Gameplay demonstration video

## Opening the Project

Open the repository's root folder as a project in Unity Hub. Unity will restore the necessary packages using the files in `Packages/`.
